Entry for the make.fun bounty [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5).

## What it does

`main.ts` writes one line of honest, funny software error copy to `/output/entry.txt`:

> The server crashed while saving your file. Your work is safe, the server is not. Wait 30 seconds and try again.

## Run

```sh
node main.ts
```

The output is deterministic: the same fixed text is written on every run.
